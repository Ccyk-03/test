# 抽卡师的魔法 — macOS 安装包构建操作手册

> 本手册教你在一台 **Mac（苹果电脑）** 上，把项目打包成可直接安装的 `.pkg` 安装包（含防拷贝机制）。

---

## 一、先说清楚：为什么要一台 Mac

macOS 的安装包（`.pkg` / `.dmg`）只能由苹果系统自带的工具生成（`pkgbuild`、`productbuild`、`hdiutil`）。这些工具**在 Windows / Linux 上不存在**，所以：

- ✅ Windows 安装包：可在 Windows/WSL 上直接打包（已交付）
- ❌ macOS 安装包：**必须在一台 Mac 上打包**

这不是代码问题，是苹果平台的硬性限制。

---

## 二、准备清单

| 项目 | 说明 |
|---|---|
| 一台 Mac | macOS 11（Big Sur）或更高，Intel 或 Apple 芯片均可 |
| 打包材料 | 本目录 `packaging/macos/` 及项目源码（下面会讲怎么拿） |
| 网络 | 首次构建需联网下载「便携版 Python」（约 50MB） |
| 时间 | 全程约 5~10 分钟 |

> **Mac 上不需要安装 Python、不需要安装 Node.js** —— 便携版 Python 由脚本自动下载，前端已预编译。

---

## 三、操作步骤

### 第 1 步：把项目拷到 Mac

把整个项目文件夹 `GPT_Chat` 拷到 Mac 上（U盘、网盘、隔空投送均可）。

> 提示：如果项目里有 `node_modules`、`backend/data`、`__pycache__` 等大目录，可以删掉再拷，不影响打包。

### 第 2 步：打开终端

在 Mac 上按 `Command + 空格`，输入「终端」或「Terminal」，回车打开。

### 第 3 步：进入打包目录

在终端里输入（把路径换成你实际的路径）：

```bash
cd ~/Downloads/GPT_Chat/packaging/macos
```

> 如果项目放在了「下载」文件夹，路径通常是 `~/Downloads/GPT_Chat/packaging/macos`。

### 第 4 步：给脚本加执行权限

```bash
chmod +x build_macos.sh postinstall.sh launcher.sh
```

### 第 5 步：运行打包脚本

```bash
./build_macos.sh
```

脚本会自动完成：
1. 检查环境
2. 使用预编译好的前端（无需 Node）
3. 下载便携版 Python 运行时
4. 安装 Python 依赖
5. 装配 `.app` 应用包
6. 生成 `.pkg` 安装包（含防拷贝 postinstall 脚本）

看到 `构建完成：dist/抽卡师的魔法-1.0.0.pkg` 就成功了。

### 第 6 步：找到安装包

在 Finder 中打开 `packaging/macos/dist/` 文件夹，里面就是：

```
抽卡师的魔法-1.0.0.pkg
```

这就是可以交付的 macOS 安装包。

## 四、安装测试（可选但建议）

1. 双击 `抽卡师的魔法-1.0.0.pkg`，按提示安装（会装到「应用程序」目录）
2. 安装完，打开「应用程序」→ 双击「抽卡师的魔法」
3. 浏览器会自动打开登录页 → 用 admin/admin123 登录测试

### 验证防拷贝机制

1. 在 Finder 里把「应用程序」里的 `抽卡师的魔法.app` 复制到桌面
2. 拷贝到另一台 Mac（或删掉本机标记文件）再运行
3. 预期：程序弹窗「程序未通过安装校验，请使用安装包重新安装」并退出

## 五、常见问题（FAQ）

### Q1：脚本报「Python 下载失败」
便携版 Python 的下载地址可能随版本更新失效。打开 `build_macos.sh`，找到 `PY_TAR=` 和 `PY_URL=` 两行，到下面网址找到最新地址替换：
https://github.com/astral-sh/python-build-standalone/releases
（选 `install_only` 的 macOS 包，Apple 芯片选 aarch64，Intel 选 x86_64）

### Q2：脚本报「Permission denied」
说明没执行第 4 步，重新运行 `chmod +x build_macos.sh postinstall.sh launcher.sh`。

### Q3：安装 .pkg 时被 Gatekeeper 拦截
这是未签名的正常现象。两种解决：
- 右键 .pkg → 打开 → 仍要打开
- 或系统设置 → 隐私与安全性 → 允许

> 正式对外交付建议做**代码签名**（需要 Apple 开发者账号，99 美元/年），否则用户会看到「未验证开发者」提示。

### Q4：双击 .app 没反应
查看日志 `~/Library/Application Support/抽卡师的魔法/logs/app.log`，把内容反馈给开发者。

### Q5：模型调用报 429/402
这是免费模型限流/额度问题，与软件无关。在管理端换成付费模型（如 `openai/gpt-4o-mini`）即可。
